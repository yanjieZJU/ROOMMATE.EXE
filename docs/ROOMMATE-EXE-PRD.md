# 《合租七日 / ROOMMATE.EXE》PRD

## 1. 产品概述

《合租七日》是一款约 12–15 分钟的单人像素生活模拟。玩家与由 Jev 控制的室友住进同一套剖面公寓，共同生活七天；第七晚双方秘密决定续租或搬走。

Jev 不生成剧情、画面或动作后果，只在游戏引擎给出的真实可执行动作中使用 `Choice` 做判断。玩家看到的首先是一个角色在生活，结局后才可查看支撑这些行动的概率记录。

## 2. 用户价值与成功标准

- 一分钟内完成移动和第一次物品互动；
- 一局中可明确观察至少三个 Jev 自主动作；
- 玩家通过行动证据形成对室友的理解，而非读取人格总结或好感度；
- 四种续租组合都能出现，且结局可追溯到真实判断；
- 不同玩家行为能产生可见的世界变化与行动轨迹，形成重玩动机。

## 3. 核心体验

玩家使用方向键或 WASD 在固定镜头的公寓剖面中移动，靠近物品后触发情境动作。游戏持续推进，玩家不操作时 Jev 也会生活。七天固定事件依次出现：搬入、最后一份晚餐、安静工作、访客、设备损坏、身体不适与停电、租约到期。

每个动作都由引擎定义前置条件、时长、动画、状态后果和记忆事实。Jev 每次只从当前合法的 3–7 个动作中选择；续租时只从“续租”和“搬走”中选择。任何动作都不是弹窗式剧情分支，而会直接改变角色位置、物品状态或后续处境。

## 4. 玩家流程

1. 打开网页，阅读简短操作提示并开始七日合租；
2. 在公寓中移动，与床、冰箱、灶台、沙发、留言板等对象互动；
3. 观察 Jev 基于当下状态与共同事实执行动作；
4. 处理每天发生的环境事件，接受未解决后果跨日延续；
5. 第七晚先秘密选择是否续租；
6. 同时揭晓双方卡片，得到四种结局之一；
7. 查看七日关键决策，或下载脱敏 JSON 记录。

## 5. 信息与视觉设计

整套公寓采用单屏房屋剖面：二层是双方卧室与平台，一层是厨房、客厅、浴室和玄关。美术使用奶油墙面、珊瑚红、暖橙、深青与少量冷蓝的高密度像素风。

HUD 只显示日期、时间和已经公开的事实；不显示好感度、信任值或续租倾向。需求通过角色动作和简短提示表达。模型概率只在结局后的决策档案中出现。

## 6. 数据与隐私

- 无需账号、照片和自由文本；
- 完整存档与判断记录只保存在浏览器 IndexedDB；
- 服务端不保存生活内容；
- 运行指标只包含模型、token、问题数、延迟、重试与错误码；
- 仅允许 `jev-1.13-free`，失败时暂停并提示重试，不静默切换付费模型；
- 导出的 JSON 不含 API Key、IP、installation id 或服务端日志标识。

## 7. MVP 范围

包含固定公寓、两名角色、7 天日程、约 16 个物品、20–30 个宏动作、固定事件、四种续租结局、本地恢复和判断档案。

不包含多 Agent 小镇、自由聊天、生成式剧情、地图编辑、联网、账号、排行榜、云存档和手机触控专项适配。

## 8. 验收

- Jev 连续判断只能返回候选集合内动作，概率表必须完整；
- 过期状态响应不得提交；刷新只恢复最后一次原子提交；
- 模型失败时世界暂停，玩家可重试且不发生随机回退；
- 七日事件和四种结局均有自动化覆盖；
- 生产构建、单元/集成测试和浏览器端完整流程全部通过。
